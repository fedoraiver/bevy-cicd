# Agent Note: 从项目装配生成 ECS 架构站点

Status: implemented — 生成工作流与导出契约已实现

## Problem

共享 Pages 工作流可以发布静态产物。需要从 Bevy 应用的实际编译结果和运行时注册生成可追溯的架构图。

## Decision

分析器根据选中 Cargo 包的编译单元确定项目类型和装配关系。项目通过可选导出入口提供真实调度，共享生成工作流在隔离检出中构建静态站点。发布沿用站点证明、默认分支检查和线上验证。

## Changes

[接入指南](../../../../README.md) 记录导出 crate、生成工作流和静态发布接口。生成工作流输出编译器事实与调度审计产物。

## Alternatives considered

把编译器和图生成工具复制到各调用项目会分散版本管理。共享生成器统一分析与渲染版本，调用项目维护自身的 App 装配。

## Consequences

调用项目须能用共享分析器固定的编译器构建，并提供 debugdump 导出入口。未完成任一生成或检查步骤会阻止本次站点发布。

## Verification

验证覆盖非固定包名的编译器模型、无窗口调度导出、生成器回归和调用项目的 Actions 架构构建。运行记录随发布交付。
